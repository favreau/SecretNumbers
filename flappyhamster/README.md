# Flappy Hamster

Runner mobile en **5 niveaux** :

| Niveau | Décor | Difficulté | Chiffres |
| --- | --- | --- | --- |
| 1 | Forêt | Facile | 2 |
| 2 | Neige | Moyen | 3 |
| 3 | Plage | Difficile | 4 |
| 4 | Ville | Très difficile | 5 |
| 5 | Espace | Final | 6 |

À la fin de chaque niveau : ouvrir le **cadenas** avec les chiffres trouvés (dans l’ordre).

## Local

```bash
python3 -m http.server 8765
```
