# Secret Numbers

Deux mini-jeux HTML standalone, déployés sur **GitHub Pages à chaque push sur `main`**.

| Jeu | Chemin |
| --- | --- |
| Hub | `/` |
| Secret Numbers (fractales 360°) | `/secretnumbers/` |
| Flappy Hamster (runner) | `/flappyhamster/` |

## URLs

Après le premier déploiement :

- `https://favreau.github.io/SecretNumbers/`
- `https://favreau.github.io/SecretNumbers/secretnumbers/`
- `https://favreau.github.io/SecretNumbers/flappyhamster/`

## Déploiement

Le workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) publie le site via GitHub Actions.

Dans le dépôt GitHub : **Settings → Pages → Source = GitHub Actions**.
